**(c)** The SCTP course assumes a POSIX shell (bash or zsh). In your course material, you may encounter commands like these:

```bash
touch notes.txt
export API_KEY=abc123
chmod +x setup.sh
source venv/bin/activate
```

Give **one concrete reason** why running commands like these on Windows PowerShell can fail, even though some commands look similar to PowerShell at first glance. A general-knowledge answer is fine; you do not need to have used PowerShell yourself.

**Answer:**
_Commands like export, chmod, touch, and source are POSIX shell (bash/zsh) built-ins or Unix utilities that don't exist natively in PowerShell — PowerShell uses its own cmdlet syntax instead (e.g. $env:API_KEY = "abc123" instead of export API_KEY=abc123, and it has no direct equivalent to chmod since Windows uses a different file-permission model based on ACLs rather than Unix-style rwx permissions). So even though a command like touch notes.txt might look like it could work, PowerShell will typically respond with something like touch: The term 'touch' is not recognized as a name of a cmdlet..._
